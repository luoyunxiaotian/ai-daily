## 三、15 条精选 · 甲组 AI Coding（8 条）

### A1 · OpenAI 推出 Agents API 公测：把 Codex 的「harness」直接卖出去

- **内容**：OpenAI 于 **2026-09-10** 宣布 **Agents API 进入公开测试**，面向所有开发者开放。核心是把**支撑 Codex 与 ChatGPT Work 的 agent 基础设施**以编程接口形式对外提供：一次 `client.beta.agents.sessions.create` 调用即可指定**模型 / 工具 / 执行环境 / 任务**，创建可投入生产的长时运行 agent。三项关键能力——**上下文自动压缩**（临近窗口上限时自动压缩早期上下文）、**工具搜索与并行调用**（按需加载工具定义、并行执行）、**多子代理协同**（主 agent 拆解任务下发至独立维护上下文的子 agent，再汇总）。
- **生态**：OpenAI 托管沙箱 + 自托管（`codex exec-server`，数据不出 VPC）+ 9 家一级集成伙伴——**Blaxel、Cloudflare、Daytona、DigitalOcean、E2B、Modal、Oracle、Runloop、Vercel**。原生支持 **MCP**、自定义函数与网页搜索等内置工具。

- **时效**：官方 2026-09-10（OpenAI Developer Community 帖时间戳 09-10 20:59）。

4. **对选型的直接含义**：如果你的负载是**长时 Agent / 工具调用密集**，视角 B 比视角 A 更贴近真实账单；如果是**单轮问答/短对话**，视角 A 更准。**只盯榜单总评分选型，会系统性高估闭源旗舰的经济性**。
