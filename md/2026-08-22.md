**核心事件（2026-08-21 上线，08-22 社区实测爆发）：**

1. **DeepSeek-V4-Flash-Vision-Exp（视觉实验版）上线 API**
   - 首款原生支持图片输入的 V4 系列多模态模型，补齐"文本推理专家→多模态 Agent 底座"短板。
   - 支持 JPEG/PNG/GIF/WebP；单次最多 600 张图，最长边 8192px，单图 ≤64MiB（Files API）；三种细节模式 low/original/auto，单图最多折算 **384 tokens**。

2. **免费 Files API 开放**：上传图片经 `file_id` 跨请求复用，不收存储费。
3. **DeepSeek Harness 原生支持多模态**：最新版 DSH 可直接选该视觉模型，搭配 Harness 解锁"看图雕牛/Canvas 手绘"等场景（社区实测：Blender 渲染、宇宙风 Canvas demo）。
4. **定价与 V4-Flash 一致**（CNY/百万 tokens）：高峰输入 3.0、输出 9.0；空闲输入 1.5、输出 4.5；缓存命中空闲 0.05、高峰 0.10。
   - 社区实测：按"高峰缓存未命中"计价，看一张图约 **0.12 分钱**，1 分钱理论约看 9 张；同条件下 Image 2 看一张约 2.06 分（贵近 20 倍）。
5. **llm-stats 实时榜**：DeepSeek-V4-Pro-0813 #7（54.5 / $0.48，开源头部）；DeepSeek-V4-Flash-Vision-Exp #15（48.7 / $0.27）。
