### ▍AI Coding（8 条）

**1. OpenAI 开源 Codex Harness（Apache-2.0）：AI 竞赛重心从模型转向执行层**
- **时效**：8/19 发布，8/24–25 集中发酵
- **来源**：网易、品玩、腾讯科技、硅星 Breaknews
- **内容**：OpenAI 将驱动 Codex 智能体的核心框架以 Apache-2.0 开源，提供三层集成：① `codexexec` 用于脚本/CI/后台一次性作业；② Codex SDK（TypeScript + Python）以编程方式启动与管理 Agent 任务；③ app-server 提供对话状态管理与流式事件。示例应用 Relay 演示集成至运维工作流。ARC-AGI-3 上仅优化 Harness 的推理保留与上下文压缩，GPT-5.6 Sol 得分即从 13.3% 升至 38.3%，输出 token 减至 1/6。
- **值得关注的原因**：头部厂商集体开源 Harness（DeepSeek、OpenAI、Anthropic、智谱 ZCode、Kimi Code）印证「模型决定能做什么、Harness 决定如何做完」成为共识。对企业：自托管 Agent 门槛被显著拉低，「模型—Harness—Surfaces」三层架构不再只属于少数大厂。

**2. GPT-5.6 家族登陆 Kiro（AWS 合作），Terminal-Bench 2.1 成本降 82%**
- **时效**：8/25
- **来源**：今日头条 AI 科技速览、AWS/OpenAI 合作披露
- **内容**：GPT-5.6 的 Sol / Terra / Luna 三款模型接入 AWS 软件开发智能体 Kiro。在 Terminal-Bench 2.1 中，GPT-5.6 Terra 在 Kiro 内完成任务成本降低约 82%，由 OpenAI 与 AWS 联合优化，以更少迭代与更高 token 价值产出更高质量代码。
- **值得关注的原因**：云厂商把前沿模型「预适配」进自家 Agent 产品，开发者无需自搭 harness 即可获得成本优化。对 AI Coding 选型：模型能力差异正被「模型 × 宿主优化」的复合体验抹平，成本指标比基准分更影响采用。

**3. OpenAI ChatGPT Work：Codex 改造面向非工程师，$20/月，组织订阅仅 17%**
- **时效**：8/25
- **来源**：今日头条 AI 科技速览
- **内容**：OpenAI 将 Codex 改造为面向非工程师的智能体产品 ChatGPT Work，最低订阅档 $20/月，让白领通过 LLM 自主完成多步骤工作。内部数据：6 月 98% 员工使用 Codex，但组织订阅者仅 17%、个人订阅者不足 1%，暴露 Agent 走出编程群体的可发现性瓶颈。
- **值得关注的原因**：量化了「能力很强 ≠ 采用很高」的鸿沟。Agent 产品下一阶段竞争焦点是交互范式与可发现性，而非单纯模型能力——这解释了为何 Harness 要嵌入业务软件而非聊天框。

**4. DeepSeek 上线 V4-Flash-Vision-Exp 多模态 + Harness v0.1.1-rc.1**
- **时效**：8/25
- **来源**：机器之心、财中社
- **内容**：DeepSeek 推出 V4-Flash-Vision-Exp 视觉理解模型，原生支持图片输入（认人、读截图、看图表），纯文本能力持平 V4-Flash 正式版，视觉 Agent 能力逼近 Opus-4.8；同步更新 Harness 至 v0.1.1-rc.1 提供官方多模态支持。
- **值得关注的原因**：这是 DeepSeek 从「文本/代码」向「视觉 Agent」延展的关键一步，且免费实验窗口（约至 8/27）为企业提供了低成本多模态 POC 机会；与 D1 Codex Harness 开源合看，多模态 Agent 的工具链正在快速标准化。

- **内容**：文心快码服务超 800 万开发者、2000+ 企业客户，IDC 九项评测八项满分；Kimi K3 在前端代码生成评测中登顶，是首个登顶的开源模型；DeepSeek V4 Flash 把调用成本压到同类闭源约 1/95，直接接入 Claude Code 等编程宿主。国内：字节 Trae 份额约 41%、通义灵码 800 万用户/金融渗透率 >30%、腾讯 CodeBuddy 28%。海外：Cursor 付费用户 >100 万、ARR 约 $20 亿；Claude Code 周活约 420 万；Copilot 总用户 5000 万但付费仅约 470 万、份额滑至 25%。

**6. NVIDIA Vera Rubin NVL72 实测：agentic 负载每兆瓦吞吐 +30×、token 成本 −35×**
- **时效**：8/25
- **来源**：机器之心、今日头条 AI 科技速览
- **内容**：英伟达发布 Vera Rubin NVL72 加速卡实测：在智能体工作负载下每兆瓦吞吐量较 GB300 NVL72 最高提升 30 倍，每百万 token 成本降至 1/35。同一批测试用 DeepSeek V4 Pro 跑 AgentX 负载验证开源模型在新架构上的收益。
- **值得关注的原因**：对电力受限的「AI 工厂」，同等能源预算可承载的 agentic 负载量级被重写。这直接压低了 AI Coding / 多 Agent 系统的单位经济，使「长任务、多轮工具调用」从奢侈品变为可量产能力。

**7. Google 提出 EnvHarness：让静态训练环境随 Agent 进化**
- **时效**：8/24
- **来源**：腾讯研究院 AI 速递（Google + 圣路易斯华盛顿大学）
- **内容**：EnvHarness 在静态环境外增加可编程层，通过 Stage / Contract / Chain 三类组件调整任务起点、交互规则与任务长度，无需重建环境或修改验证器；配套 EnvRigger 将策略视为黑盒，经 Observe→Diagnose→Write→Validate 四阶段自动诊断 Agent 弱点并编写验证组件。四领域五基准上平均步数减少 9.8%。
- **值得关注的原因**：把「环境即代码」引入 Agent 训练闭环，使 RL/评估环境可随策略共同进化。对 AI Coding 评测（如 Terminal-Bench、SWE-bench）意味着更可控、可复现的基准，也降低企业自建评测环境的成本。

**8. Ox Alpha「牛来」匿名模型：免费 1M 上下文，DeepSWE 80% 高于 Fable 5，8/27 免费截止**
- **时效**：8/24–26
- **来源**：腾讯证券、OpenRouter、Reddit r/LocalLLaMA
