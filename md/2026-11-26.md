## 十、方法论与免责声明

### 10.1 信源分级与验证规则

- **社区单源爆料** → 🔴 待验证 / 低置信度，不写进「已确认」条目，单列 §四。
- **≥2 个独立社区源，或 1 社区源 + 1 官媒 / 官方** → 🟡 大概率属实，注明双方口径差异。
- **官方公告 / Release Notes / 一手法定披露** → ✅ 已确认；但「已确认」只表示该事实有权威来源，不等于该产品的效果宣称已被独立验证。
- 每条社区来源标注平台、账号 / 帖子线索与时间，保留可追溯路径；对外文本不含任何本地路径与凭据类信息。
- **时效硬核实**：凡以「今日新闻 / 已确认 / 15 条精选」身份写入的条目，均对照官方一手来源核验年-月-日且年份等于 2026；官网首页横幅、版权年份、无日期搜索摘要、聚合站 `Updated / Last checked / Data as of` 一律不作发布日期依据；无法核验具体日期的一律降为「背景 / 待验证」。
- **三口径不可混算**：LiveBench、Artificial Analysis、llm-stats 的评测任务、推理档与采样窗口不同；本报告自算的 Price vs Performance 采用 `(20×输入 + 输出) / 21` 混合价口径，已显式声明非官方榜单。
- **承诺 ≠ 实现**：量产计划、IPO 时间表、融资进行中、产品「即将上线」均标注未来时点，不写成已发生事实。
