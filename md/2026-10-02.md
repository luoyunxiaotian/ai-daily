### A1 · NVIDIA 开放 Open Agent Safety Platform：把 agent 安全从提示词下沉到硬件

- **事件**：NVIDIA 发布 Open Agent Safety Platform，由两层组成——**OpenShell**（开源，在操作系统内核层把 agent 包进受限运行时）与 **Sentry**（跑在 BlueField-4 DPU 上的独立看门狗，可**在毫秒内隔离越界 agent**）。**120+ 家公司**加入联盟，含 Anthropic、Microsoft、Salesforce、Hugging Face、SAP、Scale AI；**OpenAI 未出现在名单中**。NVIDIA 正与 Arm、Intel 合作把 Sentry 带到 x86。
- **来源**：NVIDIA 官方 + Wired + The New Stack + AP（经 robot24 / ai2day / SCAND 转述）
- **时效**：09-30 发布，**10-01 集中扩散 → 窗口内**
- **置信度**：<span class="t-conf">已确认</span>
- **值得关注的原因**：这是 agent 安全的**范式转移**——过去靠"提示词护栏 + API 限流"，本质是让模型自己管自己；现在把执行边界放到**模型无法影响的硬件层**。同时它暴露了行业裂痕：**最大的模型厂商缺席**。
