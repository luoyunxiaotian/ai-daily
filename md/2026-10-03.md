## 三、 15 条精选 · 甲组 AI Coding（8 条）

### A1 · Pi 1.0：曾公开拒绝 MCP 的极简 agent harness，反向原生支持了 MCP

- **事件**：Earendil（Armin Ronacher 与 Colin Daymond Hanna 创立，Accel / Balderton 背书）发布 **Pi 1.0**，MIT 许可。核心变化是 **Codemode** —— 一个 JavaScript 执行环境，让 agent 把多个工具调用写进一段脚本里合并执行，**并原生支持 MCP**。这是明显的立场反转：Pi 此前长期以「可组合性差、吃 token」为由拒绝 MCP。官方给出的理由是协议本身演进成熟，且 Pi 为 Jev 集成本来就需要类似执行环境。其他更新：工具按需加载（省上下文）、Anthropic 模型缓存预热（降成本与等待）、会话中途插入 system message、默认全屏 TUI。同期发布实验性的 **Pi Durable**（长时运行 agent 框架）。反转为成本所驱动：Codemode 把一个 GPT-5.6 的示例从约 5,300 prompt token 压到约 3,300，**省 40%**。
- **来源**：Earendil 官方发布帖 + Hacker News（id `49926069`）+ Startup Universal + Podimo HN 回顾
- **时效**：**10-01 19:33 UTC = 北京 10-02 03:33，距本期窗口起点早约 2 小时**，按「窗口边缘」计入；10-02 全天持续发酵
- **置信度**：<span class="t-conf">已确认</span>（官方发布帖 + MIT 许可可核验）
- **值得关注的原因**：MCP 已经从"要不要接"变成"怎么接才不亏 token"。Codemode 用**代码执行**而非**工具描述塞进 prompt**来接 MCP，等于给整个行业提供了一个可复制的成本解法；一个以克制著称的项目主动拥抱它，说明这条路走通了。

### A2 · Anthropic 疑似在 `Fable 5.1` 标签下灰度下一代旗舰（社区称「Fable 5.5」）

### A3 · Cloudflare 发布 Clef / Clef-flash 决策模型：不生成句子，只返回选择与概率

- **事件**：Cloudflare 推出 **Clef** 与 **Clef-flash** 两款决策模型，**基于 Qwen、Apache 2.0 许可**。它们不生成文本，而是把文本和图像分类进预定义答案，并返回**选择、分数或真值概率**，用于路由客服工单、识别可疑网站、挑选 agent 的下一步动作等。支持图像输入、**64K 上下文**，兼容 Jev API。官方称 **Clef-flash 约 39 毫秒**完成分类，**比 TypeSafe AI 的 Jev 快 10 倍以上**。Cloudflare 的表述是：有了 Clef，AI agent 做结构化决策**不再需要人在环内**。
- **来源**：Cloudflare 官方博客（blog.cloudflare.com/clef-decision-models/）+ Hacker News（id `49923692`）+ the-decoder（10-02）
- **时效**：10-02
- **置信度**：<span class="t-conf">已确认</span>（官方博客 + 许可协议可核验）
- **值得关注的原因**：这是把「小模型做判断」这一层**产品化并开源**的动作。它与 AWS Strands Decider 2B（上期 A7）、Jev 构成同一赛道：模型的产出从 token 变成**决策**。39ms 的意义不在快，而在于**可以放在 agent 主循环里同步调用**而不拖慢链路。
