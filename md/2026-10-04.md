- **事件**：Claude Code 负责人 Boris 官宣 **Claude Mods**（插件可修改更深层行为，内置 `you-should-know` mod）后，**DeepSeek Harness 团队负责人崔添翼**转发祝贺，并公开对比两条路线：按他的表述，**Claude Code 是把部分能力开放为 Mods，而 DeepSeek Harness 从一开始就主张「Everything is a Plugin，一切皆插件」**——模型、工具、Skills、会话、沙箱、文件系统、Agent Loop、任务编排、UI 全部可作为插件组合、替换、扩展；在创造模式里用户可以现场让 agent 检查当前系统、编写插件并保存。他开玩笑说团队琢磨「Plugin Engineering」已久，"现在是不是该叫 Mod Engineering 了"。

### A5 · Meta Superintelligence Labs 提出「锐化税」：大采样预算下，base 模型 + 轻 harness 能解出 RL 模型解不出的题

- **事件**：**Meta Superintelligence Labs** 论文提出 **Sharpening Tax（锐化税）**。核心发现：在 **BFCL v4 multi-turn、ACEBench、WebShop** 三个 agentic 基准上，**带轻量 harness 的 base model 在采样预算 K 很大时，往往比 RL 后训练模型解决更多任务**。机制是：**RL 把每个问题推向「总是解决 / 从不解决」两个极端——一致性上升，覆盖度（coverage）下降**，这个损失被命名为"锐化税"。后训练模型仍赢 **pass@1**，但**大 K 下 base model 常解出 RL 模型从未解出的任务**。同期 Yoav Goldberg 补充：后训练不只是塑造行为，还**注入了软件工程、数学、计算机使用等知识**。
- **来源**：Meta Superintelligence Labs 论文（经 AGI Hunt 10-04 收录，含 `details` 原文链接）+ COLM 论文 *Why Do Reasoning Models Lose Coverage?* 互证
- **时效核验**：**AGI Hunt 10-04「Research」节新增 ✅**；上期未出现 → 判为**本期新增**
- **置信度**：<span class="t-prob">大概率</span>（实验室论文 + 独立 COLM 论文互证，但**未见第三方复现**）
- **为何值得关注**：这是对"后训练一定更好"这一默认假设的**直接挑战**。如果你的使用场景是**单发、要求稳定命中**（客服、批处理），后训练模型的 pass@1 优势仍然成立；但如果是**多轮采样、允许重试、追求覆盖长尾**（agentic 任务、批量修 bug），**base + harness 可能是更划算的组合**。这也解释了为什么"harness / scaffold"这一层在今天反而越来越重要——**模型吃不掉的那部分，正是 harness 在补**。（可与本期 A1 的 Mods、D1 的插件化对读：三者都在争夺"模型与外层之间的那一层"。）
