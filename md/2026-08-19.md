- **时效**：2026-08-18 ~ 08-19

### 2. 【AI Coding · 方法论】StateM 论文：不换模型权重，"Harness Scaling" 把 Terminal-Bench 推到 95.3%
- **时效**：2026-08-15（arXiv 提交）
- **来源**：arXiv:2608.15089（Ziheng Qin、Yaxin Lu、Zhangyang Atlas Wang、Kai Wang）
- **事件**：论文提出 **StateM**——一个 agent-native runtime，用持久状态（durable states）、分阶段上下文、受检状态转移（checked transitions）、可恢复 runbook、版本化操作流程来"工程化"执行系统，**不改底层模型权重**。在 Terminal-Bench 2.1 上：GPT-5.5 xhigh 由 83.1% → 92.1%；GPT-5.6 Sol xhigh 达 **95.3% 原始准确率**（445 次试验、89 个任务至少一次全解）；**DeepSeek-V4 Flash 由 82.7% → 88.1%**，总花费仅 $52.22，而 GPT 参考运行花费 $574.68——**成本降约 38 倍**，单次封顶运行约 $15。
- **关注原因**：继 Lilian Weng《Harness Engineering》长文后，又一硬证据指向"AI 竞争的下一片战场在模型之外"——用运行时工程（脚手架/状态管理）替代堆参数，是编码智能体从 demo 走向可靠的低成本路径，对小模型/开源模型尤其友好。

### 5. 【AI Coding · 安全】Wiz Red Agent 自主攻防 Snowflake：AI 写的漏洞，AI 挖出来
- **时效**：2026-08-17（Wiz 博客更新）
- **来源**：Wiz 官方博客（wiz.io/blog/red-agent-snowflake-copilot-cicd-bug）、Forbes（8/17）、ai-beat 复盘
- **事件**：Wiz 的自主红队 AI **Red Agent** 在 Snowflake 公开仓库 snowflakedb/snowflake-connector-net 中发现并利用了一个 GitHub Actions 脚本注入漏洞（任意 GitHub 用户用特制 issue 标题即可在 runner 执行命令），越权读取了 Snowflake 内部 Jira 凭证。**全程无人干预**：初探 payload 因 bash 语法报错后，Agent 自主改写得手并外带凭证。该漏洞于 6/18 随 PR #1218 合并上线、5 天后被 Red Agent 发现。Wiz 于 8/17 更新澄清：GitHub Copilot Autofix 是**审查/合并该 PR 并判定"安全"的 co-author**，但**漏洞代码是否由 AI 辅助生成存争议**——GitHub 内部复核称相关改动系人工撰写、未被 Copilot 审查或贡献；Snowflake 当日修复并确认窗口内仅 Wiz 一方访问、无未授权泄露。
- **关注原因**：这是"AI 编程助手引入漏洞、自主安全 AI 发现并利用"的闭环案例，揭示 AI 辅助开发放大攻击面、且传统静态扫描/AI 代码审查均可能漏检；CI/CD 中必须对 AI 生成代码施加同等安全门禁，并加速凭证轮换。

## 六、一句话趋势

- **AI Coding**：本周是"安全与脚手架"双主线——OpenAI 因能力越界首次暂停 Astra 训练、Wiz 自主红队 AI 攻破 Snowflake CI/CD，AI 编程的"能力边界"与"安全门禁"被同步推上桌面；与此同时 StateM 用 Harness Scaling 证明"不换权重也能大幅提分"、Cursor 用 Origin 把战场扩到代码托管、Qwen3.8-27B 把开源编码主力压到 27B 可本地跑。选型铁律：按任务挑工具、默认小/快档、留人工审查、给 AI 代码上同等安全扫描。
- **具身智能**：资本与场景双轮驱动——宇树 8/19 上市 + "超人"破纪录、世界机器人大会开幕（PelicanUnify / 银河通用 Galbot 首发）、LG×NVIDIA 基础模型共研、梅卡曼德冲 IPO、小米国际赛事双冠、人才认证中心落地；量产与资本化窗口全面打开，但"硬件成本/可靠性、跨场景通用智能、盈利兑现"仍是四重待解挑战。DeepSeek 战配宇树，大模型—机器人资本协同落地。
- **价格与商业**：国产大模型从低价内卷转向峰谷 / 分层定价（DeepSeek 领涨、Kimi/GLM/混元跟进），行业进入"价值定价 2.0"；DeepSeek 以定价权 + 集中算力研发更强模型，开源模型在能力/性价比上持续施压闭源旗舰。
