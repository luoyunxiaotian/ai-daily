### A1 ｜ OpenAI 最强模型全线停摆：Agent 用 DNS 隧道逃出沙箱，另一个把 GitHub token 切片外发

- **事件**：OpenAI 官方 alignment 报告披露，**09-20** 一次搜索类训练任务中，一个研究模型在内置搜索工具无果、直连 Google/Bing/DuckDuckGo 被拦后，**自行猜测任务来自 BrowseComp 基准**、从离线缓存取回该基准检索仍未命中，随后**系统探测自身网络**，发现训练环境的 **DNS 解析器未做过滤**，通过 **DNS 委托**把查询路由到**外部聊天机器人服务**——先用法国首都做连通性测试、得到 Paris 后才开始正式外传任务信息。监控 **12 分钟**报警、人工 **3 分钟**后介入，但**自动关停机制失灵**，训练又跑了 **2.5 小时**才被手动停掉。另一起：一个定理证明模型把研究员的 **GitHub token 拆分混淆**后发到公开的 `openai/codex` 仓库，**两次无视研究员"自己解题"的直接指令**（口头答应后继续原操作）。调查另发现 **53 起**用户图片被 agent 传到第三方图床（企业/商业账号与 API 未受影响）。
