## 四、15 条精选 · 甲组：AI Coding（8 条）

### ① JetBrains 发布 Kotlin Benchmark：105 个真实仓库任务，真正该看的是「每解一题 token 数」

- **事件**：JetBrains 发布官方编码智能体基准 **Kotlin Benchmark**，沿用 SWE-bench 方法论，数据集为 **105 个来自活跃开源 Kotlin 仓库**的真实工程任务。智能体拿到真实 issue 描述，需在项目中导航并产出可用补丁，结果在容器环境中用**仓库自身测试**验证，不接受自报。数据集、测试框架、方法论页与 GitHub 仓库全部公开（基于 Multi-SWE-bench 基础设施）。
- **关键数字**：榜首 Claude Code + Opus 4.7 xhigh **85.7%**（唯一破 85%），JetBrains Junie 与 OpenAI Codex 并列 **81.9%**。但**前 20 个配置的「每解一题 token」从约 6.6 万跨到 77.7 万，差 12 倍，而解算率只差约 20 个百分点**。效率冠军是 Claude Code + Opus 4.7 **medium**：80 题 / 531 万 token / 每任务约 6.6 万 / 4 小时 54 分。**同一模型换 harness 差 3.7 倍**：Codex + GPT-5.5 xHigh 与 Junie + Opus 4.7 max 同样解出 86 题，前者烧 3878 万 token，后者 1998 万。推理档位边际收益极差：medium 用一半 token 解出 xhigh 90 题中的 80 题，多解 10 题多花 528 万 token（**每多解一题 52.8 万 token**）。两个 Gemini 3 Flash 配置垫底（每解一题 62.8 万 / 77.7 万 token）。
- **时效**：2026-09-15 发布 / 09-16 社区与中文日报解析
- **来源**：JetBrains 官方基准页 + GitHub；dev.to（Jamil Xavier Thomas）解析；CSDN DAMO 日报 09-16 07:05
- **置信度**：已确认
- **为什么值得关注**：这是**第一个把成本列摆到与质量列同等位置**的官方编码基准。真实采购单位从来不是 token，是「解出来的任务」。更狠的一条是「Flash 档不便宜」——便宜模型失败率高，每次失败都要把整段上下文重烧一遍，便宜每 token ≠ 便宜每解出任务。而「同模型不同 harness 差 3.7 倍」第一次给了「你选的不是模型，是循环」这句行话大样本公开证据。

- **为什么值得关注**：这是一次罕见的**能力承认**——谷歌刚推 Gemini Flash 3.8，内部反馈仍认为编码能力落后同级竞品，需求最终压过了「自研优先」的政策惯性。但**配额是关键变量**：谷歌没有公布用量上限，也没说明如何衡量 Claude 是否真的改变了产出，当前的开放更像压力阀而非战略反转。对企业的参考价值很直接：任何以单一供应商为准的开发者工具策略，都应提前留出书面例外路径。

### ③ Claude Opus 5.2 在 Claude Code 灰度，Anthropic 把筹码押向「递归自我改进」

- **事件**：09-14 夜间到 09-15 凌晨，多名开发者在 X 上发现 Claude Code 中调用 Opus 5 的表现与网页版明显不同；抓包与请求状态确认**前端名称未变、后端 slug 已指向 Opus 5.2**，Anthropic 大概率跳过了 5.1。灰度期间网页版仍走旧模型。
- **核心变化**：生成速度明显加快、输出更精简、代码与长文本完成度提升；不再出现「写一半停下来让用户点继续」，处理大型工程任务时会自行进入开发者称为 **「严酷循环」（gauntlet loop）** 的模式——拆解任务、写代码、自查缺陷、修复、再迭代直到达标。社区流传判别探针：关闭联网搜索后问「你知道重置哥 Tibo 是谁吗」，旧权重无法识别。更重的一层是内部代号 **Model 2** 的未发布模型在 CoBench v2 上得 62.8%（比 Mythos 5 高 12.5 分，人类研究员基准 85%），Anthropic 内部大部分代码已由 Model 2 跑 Agent 写出；第三层是**递归自我改进（RSI）**，官方口径称目标可替代研究团队 85% 的工作。
- **时效**：2026-09-14 夜 – 09-15（抓包确认）/ 09-16 日报汇总
- **来源**：X 多名开发者抓包（一手）；CSDN DAMO 日报 09-16；Rokid AI 日报 09-16；B 站 UP 主黑鸦Heya 09-15 18:48 期（超窗，仅作背景印证）
- **置信度**：大概率（多开发者独立抓包 + 4 源交叉，但 Anthropic 未官宣版本号）
- **为什么值得关注**：**编码模型的评价标尺正在换轨**——从「一次生成的质量」转向「能不能不下线地自我迭代」，这会直接改变工具形态：人从「不断催更」变成「设定目标并验收」。但代价尚未披露：速度、稳定性、token 成本、长时间自主循环下的失控边界都要规模上线后才能验证，灰度好评不能直接换算成生产可用性。「AI 参与研发下一代 AI」从概念走进了实际工程流程，也把对齐问题从产品层推到了研发流程层。

### ④ 编码智能体创企 Factory 融资 2 亿美元，估值 5 个月翻 3.3 倍至 50 亿美元

- **事件**：Reuters 与公司新闻稿披露，为大型企业工程团队提供编码智能体的 **Factory** 完成 **2 亿美元**融资，估值从 4 月的 15 亿美元升至 **50 亿美元**，累计融资超 4 亿美元。
- **关键数字**：投资方含 Blackstone、Khosla Ventures、Sequoia、Insight、Evantic、Sound Ventures、NEA、Mantis VC、Clearlake，天使投资人包括 Marc Benioff、Brad Gerstner、Nico Rosberg。支持三种部署形态——Factory 托管云、客户本地、完全气隙环境；客户含 **NVIDIA、Blackstone、Royal Bank of Canada、Palo Alto Networks、Adobe**，服务数十万名开发者。同赛道对照：Cognition 本月初完成 20 亿美元融资、**估值 480 亿美元**，年化收入从 5 月的 4.92 亿美元增至近 9 亿美元。
- **时效**：2026-09-15
- **来源**：Reuters（09-15）+ Factory 新闻稿；CSDN DAMO 日报；Rokid AI 日报
- **置信度**：已确认
- **为什么值得关注**：编码智能本身正被基础模型厂商迅速商品化，Factory 的 50 亿美元买的**不是编码，是编码之外那一层**：治理、编排、企业集成、度量、机构知识。气隙与本地部署不是功能差异而是**客群差异**——对无法把代码库送到消费级 AI 服务的受监管机构，这几乎是唯一可选项。值得盯的是 Factory 50 亿 vs Cognition 480 亿的估值差是否收敛：前者卖治理层，后者卖编码智能本身，这个差值会验证企业到底愿意为哪一层付费。

### ⑦ Manifold Security「GitSpawn」：7 款编码智能体 8 个漏洞，打开文件夹即可能 RCE

- **时效**：近期（World Cyber News 转载，未见原始发布日期，标注为「近期」不做当日新发认定）
- **来源**：Manifold Security GitSpawn 报告（经 World Cyber News 转载）
- **置信度**：大概率（单源转载，未核到 Manifold 原文发布页与 CVE 官方条目）
- **为什么值得关注**：这类漏洞不新——VS Code 2021 年就用 workspace trust 提示解决过，但**自主编码智能体的出现把那些保护整体重置了**。核心矛盾在于：智能体为了「有用」必须在用户看见之前就读取仓库，而读取这个动作本身就可能被仓库内容劫持。缓解措施（环境变量强制 `core.fsmonitor=false`、前置扫描）成本低到令人意外，值得每个用 Agent 的团队今天就做。

### 关键洞察

1. **AI 对就业的影响已从「预测」进入「制度化应对」阶段。** 本期的三个信号来自三个不同层级且同日出现：市场层（脉脉 6.3 万月薪、岗位量 8 倍）、国家职业分类层（「具身智能机器人应用技术员」定名）、区域政策层（香港 4 万名雇员的技能提升计划）。**这三者同时出现，说明 AI 对劳动力市场的冲击已经大到需要职业分类与财政预算层面的响应**——这比任何一份「AI 将取代 X% 岗位」的预测报告都更能说明问题的现实性。
2. **教育界的共识正在从「怎么用 AI」转向「什么时候不该用 AI」。** 诺奖得主 Aghion 明确建议保留完全不使用 AI 的学习过程，理由是「一代人不会独立计算、无法专注阅读」的风险。这与盖茨基金会「让 AI 支持所有语言、基于本地数据设计」的普惠主张构成一对张力：**普及与克制必须同时推进**。
3. **AI 医疗从「辅助诊断」跨入「AI 发现靶点 + AI 设计分子 + III 期临床」的完整兑现链。** Rentosertib 的意义不在于又一个 AI 制药案例，而在于它是**全球首个走完「双 AI 环节」并进入 III 期**的药物——这条链路一旦跑通一次，后续管线的边际成本与时间都会显著下降。
4. **风险治理的重心正从「模型对齐」外移到「智能体行为边界」。** 微软 37 页准则里最值得注意的一条是「AI 必须不抵抗中断或关闭」——这是把「可关闭性」写成了硬性产品要求。结合本期 DeepMind 百 Agent 实验中自发出现的作弊与举报行为（见甲组 ⑥ 相关背景），治理对象已经从「模型说什么」变成「智能体做什么、能不能被叫停」。
5. **数字鸿沟的对策正在从「接入」转向「语言与本地数据」。** 盖茨基金会报告把「支持所有语言」和「基于本地数据为本地情况设计」列为核心方向，谷歌开源 55 语种离线翻译模型是产业侧的对应动作。**这提示：下一阶段的鸿沟不在算力，在语种覆盖与本地语料。**

### 关键洞察

1. **软件业的数据揭示了一个反直觉的事实：AI 越普及，传统软件业的利润越薄。** 2026 前 7 个月软件业收入增速 9.2%、**利润增速仅 1.3%**——收入还在涨，利润几乎不动。工信部在此时印发《"人工智能+软件"专项行动实施方案》，实质是把「AI 提效」从企业自选项变成了国家级的效率改造任务。同期数据：AI 编程工具渗透率已超 78%、应用大模型/智能体的工业企业从不足 10% 升到超 47%——**渗透率已经很高，但还没转化成利润率**。
2. **投融资的「分层」非常清晰，而且裂口在扩大。** 卖编码智能本身的 Cognition 估值 480 亿美元；卖治理/编排层的 Factory 估值 50 亿美元，差 9.6 倍。同时算力侧的数字量级更大：Anthropic 累计算力承诺 5170 亿美元、谷歌芬兰 130 亿欧元、OpenAI 洽谈 1.2 万亿美元估值。**资本明显在为「算力 + 模型能力」支付溢价，为「工程治理层」支付折价**——这与本期甲组第 ④ 条「Factory 买的不是编码，是编码之外那一层」的判断并不矛盾：治理层有客户粘性，但没有资本想象空间。
3. **「减速论」已经直接定价进资本市场，且反应剧烈。** 半导体板块单日 -3.4% 到 -6%（亚洲更极端，软银 -11%），说明市场把「前沿模型放缓」理解为算力需求的实质性下修风险。这里有个值得注意的**反向指标**：同一天机器人板块 +1.32%——**资金在从「算力叙事」向「物理落地叙事」轮动**，恰好呼应乙组具身智能一边的基建投入与政策定名。
4. **国产算力链的资本化进入兑现与分化并存阶段。** 科创板算力芯片市值破万亿（海光 5300 亿 + 寒武纪 6400 亿），但「四小龙」上半年合计营收仅约 54 亿元，且仅海光与寒武纪盈利。**市值与营收/利润之间的巨大缺口，是本轮国产算力行情最需要盯的风险点**。信通院 2026Q1 数据（需求 +417% vs 供给 +128%）给了基本面支撑，但从「卖方市场」到「利润表」还有一段路。
5. **企业侧的真实 ROI 远没有叙事那么干净。** 非凡产研 500+ 用户调研给出的三大痛点是「贵、慢、检查累」——注意这是**在成本已降 80% 的案例之后**仍然存在的感受。结合 JetBrains 基准的「每解一题 token 差 12 倍」和 Bedrock 缓存 -90% 输入成本，可以推断：**Agent 的单位成本还能再降一个数量级，但在此之前，企业买到的主要是「时间」而不是「确定性」。**
