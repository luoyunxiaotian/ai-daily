- **时效硬核验**：每条「今日新闻/已确认」均对照官方一手来源核验年-月-日；无法核验到具体可验证日期者降为「背景/待验证」。DeepSeek 专项逐条对照官方公告 + 权威媒体时间线，未采用官网陈旧横幅作为发布日期；严格 24h 窗口（10-22 09:06 → 10-23 09:06）内检索到 API 收费发酵 + 二轮融资两条动态，故判定「今日有 D」。
- **社区快讯单列**：单源未交叉验证者标「待验证」，不计入已确认。
- **矛盾自检**：LiveBench/llm-stats/Artificial Analysis 三口径交叉，凡出现「新发版本未被榜单收录」即复核日期。
- **B 站**：消费已采集字幕产物，按 pubdate 执行 24h 窗口硬核验；未开启字幕者仅列标题；未登录风控未解析卡片者如实标注「过去 24h 无新视频」。
