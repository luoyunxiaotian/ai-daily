- **时效**：2026-10-07（美东）→ 北京时间 10-07 夜间～10-08 凌晨，**窗口内**
- **值得关注的原因**：① 价格打到与 GPT-6 Luna 完全持平（$0.10/$0.50），**轻量模型的价格战正式开打**；② 90% 的请求落在 ≤10 万 token 档（Anthropic 援引 Haiku 4.5 实测），所以这不是「长尾折扣」而是**主力调用降价**；③ 小模型首次引入可调 effort，把「便宜小模型」变成「可按需调档的成本模型」；④ 三口径同日收录，是本期唯一可归因的能力榜变动源。

### A2 · 微软 × 英伟达旧金山联合发布会：Microsoft Execution Containers 转 GA，Windows 11 把 agent 收进内核

- **事件**：10-07 在旧金山 Dogpatch Studios，Nadella、黄仁勋、Pavan Davuluri 同台。核心：① **Microsoft Execution Containers（MXC）正式 GA**——操作系统级沙箱，支持 Enforcement / Learning / Permissive 三模式，仅在 Windows 上可产出 agent 活动报告；② **Windows 要求 agent 对自身动作归因**（IT 可在 Entra / Agent 365 / Intune 中区分「agent 行为」与「用户行为」）；③ 已支持 MXC 的 agent 包括 OpenAI Codex、GitHub Copilot、OpenClaw、Replit、LM Studio、NVIDIA OpenShell、Unsloth AI，Claude Code、Manus、Perplexity、Raycast 等在支持路上；④ 硬件：Surface Laptop Ultra（RTX Spark，最高 128GB 统一内存，本地可跑 120B+ 参数 / 1M 上下文）$2,599 起、Surface RTX Spark Dev Box $5,999 起，10-16 发货；DGX Spark / DGX Station 首次上 Windows。
- **来源**：Tom's Hardware、Unite.AI、NVIDIA 官方活动博客、SSBCrack（10-07）

### 7.6 本期核心反直觉点

**① 标价一分没变，账单却降了 28.8%——只因为改了缓存读价。**
Claude Sonnet 5.5 的 AA 单任务成本从上期的 **$7.667 降至本期的 $5.461**，降幅 **28.8%**。而它的标价（$2 输入 / $10 输出）**完全没有变化**。拆开看：缓存读部分从 $4.41 掉到 **$2.206**，恰好是一半——正是 Anthropic 同日宣布的 Sonnet 5.5 缓存读价 $0.20→$0.10。
这验证并修正了上期的结论：**「标价相同 ≠ 账单相同，缓存命中率是隐藏变量」** → 本期更进一步，**「缓存读价是比标价更有效的调价杠杆」**。与 GPT-6.1 Sol（同样 $2/$10，单任务成本 $0.724）的差距从 **10.6 倍缩到 7.5 倍**，但绝对差距仍有 4.74 美元/任务。
