A1 · Anthropic 官方：因 agent 把日均合入量推到 3 万次，自研 Scion 取代 git

  • 事件：Anthropic 工程博客《Redesigning source control at Anthropic》（2026-10-13）披露——Claude 让内部代码合入量在几个月内从 5 月约 2,500 次/天涨到 9 月超 30,000 次/天（10 倍+），git 成为研发最大瓶颈。公司自研源码控制系统 Scion，并配套代码评审界面 Antique、代码搜索、细粒度源码控制 IAM 等约六个系统，7 人团队在 5 个月内把 monorepo 从 git 全量迁移。
  • 关键数字：主分支历史近 100 GB、压缩工作副本超 25 GB；每天为 CI 执行约 2,500 万次检出（不含开发者环境、agent 沙箱与研究任务），按 git 朴素取法每天将产生 超 600 PB 流量；峰值运维数百个内部 git 镜像。迁移后：Scion 基础设施 CPU/内存需求比原 git 镜像小 200 倍；CI 与研究任务检出快两个数量级（秒级而非分钟级）；仅 CI 就拿到 25% CPU 容量收益；各层缓存命中率 >99%；无 packfile 等价物，不需要仓库维护。
  • 最值得关注的一点：Anthropic 明说瓶颈已从"写代码"转移到"为人类规模建造的开发者基础设施"——原话是"The bottleneck, now, is all of the developer infrastructure built for human scale: source control, builds, and CI." 并预测未来 6~12 个月，其他使用 AI 编码工具的组织会普遍撞上同一堵墙。

7.6 本期核心反直觉点

① 标价完全相同的两个模型，账单可以差 2.75 倍——而且是"更贵的那个更强一点点"

模型输入$输出$3:1 混合价IIAA 单任务成本

两者标价逐位相同，混合价都是 $4.0，能力只差 1.4%（52.56 vs 51.83），但每个任务的真实账单差 2.75 倍。这延续并强化了上一期"标价相同 ≠ 账单相同"的结论——差异不在标价，而在每个任务消耗多少 token（长程深度工作天然吃更多上下文与输出）。

更有意思的是这个差距还在扩大：Argon 目前的 $2/$10 是首发体验价，有效期只到 2026-11-30；之后回到 $4/$20，混合价升至 8.0，性价比从 13.14 掉到 6.57——会从 AA 性价比榜第 17 位直接跌出前 20。换句话说：Argon 现在的"中等性价比"是打折打出来的，不是结构性的。

② 榜单速度下探与社区实测同向：两条独立线索指向端点变化

AA 官方速度榜 DeepSeek V4.1 Flash 187.3 tok/s（近期区间 213~226），社区开发者实测 175.41 tok/s（自称"测过的最慢"）。两者独立采样、同向下探。但正如 D3 所述，方向不可判定：变慢可能是因为换成了更强的模型/更高的推理档位，也可能是因为路由策略调整。在官方开口前，两种解释的证据权重相同。

③ 所有性价比口径的共同盲区（第四期补充）

三张性价比表衡量的都是"每美元能买到多少基准分"，但本期三条主线都不在这个度量里：Anthropic 的 Scion（200x 基础设施效率、25% CI CPU）、Google 的 Argon for Robotics（现实成功率 56%→75%）、跨维 UNITAS / 欧拉万象 UniWAM（3D 原生与 Scaling 趋势）——这些收益无法折算成"每美元多少分"。上期的结论是"只测能做什么，不测被允许做什么"，本期再加一条：也不测"它替你省掉了多少你本来要自己建的工程"。
