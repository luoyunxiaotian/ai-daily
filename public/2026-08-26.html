▍AI Coding（8 条）

1. OpenAI 开源 Codex Harness（Apache-2.0）：AI 竞赛重心从模型转向执行层

  • 时效：8/19 发布，8/24–25 集中发酵
  • 来源：网易、品玩、腾讯科技、硅星 Breaknews
  • 内容：OpenAI 将驱动 Codex 的框架以 Apache-2.0 开源，提供三层集成：codexexec（脚本/CI/后台作业）、Codex SDK（TS+Python 编程式任务管理）、app-server（对话状态+流式事件）。示例 Relay 演示集成至运维工作流。ARC-AGI-3 上仅优化 Harness 推理保留与上下文压缩，GPT-5.6 Sol 得分 13.3%→38.3%，输出 token 减至 1/6。
  • 值得关注的原因：头部厂商集体开源 Harness（DeepSeek、OpenAI、Anthropic、智谱 ZCode、Kimi Code）印证「模型决定能做什么、Harness 决定如何做完」。对企业：自托管 Agent 门槛被显著拉低。

2. GPT-5.6 家族登陆 Kiro（AWS 合作），Terminal-Bench 2.1 成本降 82%

  • 时效：8/25
  • 来源：今日头条 AI 科技速览、AWS/OpenAI 合作披露
  • 内容：GPT-5.6 的 Sol/Terra/Luna 接入 AWS 智能体 Kiro。Terminal-Bench 2.1 中 GPT-5.6 Terra 完成任务成本降低约 82%，由双方联合优化，以更少迭代与更高 token 价值产出更高质量代码。
  • 值得关注的原因：云厂商把前沿模型「预适配」进自家 Agent 产品，开发者无需自搭 harness 即得成本优化。选型焦点正从基准分滑向「模型 × 宿主优化」的复合体验。

3. OpenAI ChatGPT Work：Codex 改造面向非工程师，$20/月，组织订阅仅 17%

  • 时效：8/25
  • 来源：今日头条 AI 科技速览
  • 内容：OpenAI 将 Codex 改造为面向非工程师的产品 ChatGPT Work，最低 $20/月，让白领自主完成多步骤工作。内部数据：6 月 98% 员工用 Codex，但组织订阅者仅 17%、个人不足 1%，暴露可发现性瓶颈。
  • 值得关注的原因：量化「能力强 ≠ 采用高」的鸿沟。Agent 下一阶段竞争焦点是交互范式与可发现性，而非单纯模型能力。

  • 时效：8/25

7. Google 提出 EnvHarness：让静态训练环境随 Agent 进化

  • 时效：8/24
  • 来源：腾讯研究院 AI 速递（Google + 圣路易斯华盛顿大学）
  • 内容：EnvHarness 在静态环境外增加可编程层（Stage/Contract/Chain），无需重建环境即可调整任务起点/规则/长度；EnvRigger 经 Observe→Diagnose→Write→Validate 自动诊断 Agent 弱点。四领域五基准平均步数 −9.8%。
  • 值得关注的原因：把「环境即代码」引入 Agent 训练闭环，使 RL/评测环境可随策略共同进化，降低企业自建 Terminal-Bench/SWE-bench 类评测的成本。

8. Ox Alpha「牛来」匿名模型：免费 1M 上下文，DeepSWE 80% 高于 Fable 5，8/27 免费截止

  • 时效：8/24–26
  • 来源：腾讯证券、OpenRouter、r/LocalLLaMA
  • 内容：匿名模型 Ox Alpha 现身 OpenRouter，1M 上下文、图文视频输入、免费（约 8/27 截止）；小样本 DeepSWE 通过率 80% 高于 Fable 5/GPT-5.6；分词器指纹指向智谱 GLM-5.3（差 75 token 包装层），开发方未认领。
  • 值得关注的原因：「匿名预览 + 真实编码基准」模式再现。对开发者是低成本实测窗口；对治理是又一座「无认领/无评估/无许可」真空（见 §四 S1、§八）。
