▍AI Coding（8 条）

1. OpenAI 完全开源 Codex Harness——Agent 运行时全公开，仅改两处 GPT-5.6 Sol 在 ARC-AGI-3 从 13.3% 涨至 38.3%

  • 时效：8/19 发布博客，8/24 仍是 coding 圈头条
  • 来源：OpenAI 博客《Codex as a platform》、AIBase、aitoolsrecap
  • 内容：OpenAI 将驱动 Codex 智能体的核心执行框架 Codex Harness 完全开源（Apache 2.0），托管于 github.com/openai/codex，数天 Star 破 10 万。放出三组件：Codex CLI（codex exec）、Codex SDK（TS/Python 接口）、app-server（双向 JSON-RPC，支持实时事件流、中途打断、暴露自定义工具、拦截高危操作）。对比实验：不换模型，仅改 Harness 两处（保留推理、压缩上下文），GPT-5.6 Sol 在 ARC-AGI-3 从 13.3%→38.3%，输出 token 减 6 倍。
  • 值得关注的原因：再次印证"Agent 竞争力 = 模型 + harness + 工具集 + 运行时"的系统工程论。把运行时开源等于把"平台标准"开放给开发者——既降低锁定，又扩大 OpenAI 生态粘性。对自建 Agent 的团队，这是可直接借鉴的参考实现。

2. Cloudflare 为 Agent 造浏览器、钱包与支付协议——"无人在环"的 Agent 经济雏形

  • 时效：8/24 报道（Kitesurf 8/6 发布，钱包/x402 近两周内）
  • 来源：Cloudflare 官方公告、aitoolsrecap
  • 内容：Cloudflare 连发三件套——Kitesurf（从零用 Rust 编译到 WASM、无 Chromium 的浏览器，CPU/内存省 3–7×，通过 23.5 万项 Web Platform 测试，免费 beta）、Account/Virtual Wallet（API key 驱动、可设商户白名单与单笔上限）、x402 支付协议（边缘稳定币结算，无注册无 API key）。三者叠加：Agent 可自己浏览并付费。
  • 值得关注的原因：这是"Agent 成为 Web 主要用户"的基础设施宣言。对开发者的两个立刻后果：① 每 Agent 一浏览器的成本约束被削掉 3–7 倍；② 一旦 Agent 能自主付费，支出限额/白名单/审计必须在启用前就位。也提示竞合风险（Mastercard 的 AP4M 是竞争标准）。

3. Claude Code 登顶 Agent Harness 排名——长自主会话默认选择

  • 时效：8/24 新排名
  • 来源：aitoolsrecap 8/24 汇总（社区/第三方排名）
  • 内容：新一期 agent harness 排名：Claude Code 凭 hooks、subagents、dynamic workflows 居首，领先 Codex CLI、Cursor、Gemini CLI、GitHub Copilot。配套事实：Linear 遥测显示用 Agent 的团队周 PR 从 21 增至 65，但总开发时间仍上升——"选对 harness 值得做，但 review 不会消失"。
  • 值得关注的原因：排名的用处不在"谁第一"，而在它折射的工具分化：仓库级重构与编辑器内重命名需要不同运行时。与今日第 1、2 条合起来看，AI Coding 的竞争已从"模型谁聪明"全面转向"harness 谁好用、谁便宜、谁安全"。

4. DeepSeek V4-Flash-Vision-Exp：补的是 Agent 的"观察能力"而非又一个看图助手

  • 时效：8/21 上线 / 8/24 头条
  • 来源：DeepSeek 官方文档、机器之心、opendotnet 深度解读、llm-stats 博客
  • 内容：在 V4-Flash 上加原生视觉输入，纯文本 Agent/推理/世界知识与正式版持平；支持 ChatCompletions / Anthropic Messages / Responses API 三调用方式；图片经 Base64/URL/Files API 传入，每张最多 384 token，价格与 V4-Flash 完全相同（空闲 $0.22/$0.66，高峰 $0.44/$1.32 per M）。
  • 值得关注的原因：它解决的不是"图片里有几只猫"，而是 Agent 工作流里"看一眼再继续"——代码改完看截图判布局、报错截图先读信息、图表先识别异常再决定调哪个工具。原生视觉减少一层 OCR/视觉模型中转，且零加价，已深度接入 Harness。但 Exp 仍是实验品：OCR 精度、复杂界面、多图一致性、延迟需真实工作流验证。
